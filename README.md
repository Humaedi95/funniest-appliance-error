An entry for the make.fun bounty **"The Funniest Honest Appliance Error"**.

`main.py` writes a single line to `/output/entry.txt`: the funniest honest
error message a household appliance could show. This one comes from a washing
machine that has spent 40 minutes trying — and failing — to balance a load of
one hoodie and one sock, and has now formally given up.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
